# Hi, I'm Silvano 👋

**Junior QA Engineer** based in Madrid, focused on **front-end test automation**.
I like understanding how an application is built so I can test it with more depth: I write the requirements and test cases, run them manually first, and then automate them so they run in CI on every push.

- 🧪 Manual, API & mobile testing: test design (EP & BVA), test cases, bug reports
- 🤖 Test automation with **Cypress (JavaScript)** and **Selenium + Pytest (Python)**
- ⚙️ CI/CD with **GitHub Actions**, test suites running against sites published on **GitHub Pages**
- 🌱 Currently learning: Cypress custom commands and fixtures, and test reporting
